# Dati del negozio

Metti qui i dati per l'analista: più sono completi, migliori saranno l'analisi e i consigli.

- `vendite.csv` — una riga per articolo venduto (vedi il modello `vendite-modello.csv`).
  Va bene anche l'export del registratore di cassa / gestionale (CSV o Excel), anche con colonne diverse.
- `magazzino.csv` — articoli, quantità, data di arrivo, prezzo (facoltativo).
- `social/` — statistiche Instagram/TikTok esportate o screenshot degli insight (facoltativo).
- `note.md` — cose che i numeri non dicono: meteo, eventi in città, lavori in strada, commenti dei clienti.

Aggiorna i file quando puoi (ideale: una volta a settimana, per il report del lunedì).
